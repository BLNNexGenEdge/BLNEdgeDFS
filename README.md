# BLNEdgeDFS: Fantasy Baseball Lineup Optimizer + Prop Picks

This app is built using **Streamlit** and supports:

- ✅ FanDuel DFS lineup generation using LP optimization
- ✅ Custom fantasy point projection engine for pitchers and hitters
- ✅ Prop pick analysis using projected edge over betting lines

## 📁 How to Use

1. Clone this repo or upload files to Streamlit Cloud
2. Run `streamlit run blnedge_app.py` locally **OR** deploy via https://streamlit.io/cloud
3. Upload FanDuel salary files and/or props CSVs in-app
4. Download your optimized lineup or best prop bets

## 🔧 Requirements

- Python 3.8+
- `pip install -r requirements.txt`
